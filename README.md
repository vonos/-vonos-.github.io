# vonos.github.io / Personal Homepage

我的个人主页，基于纯静态 HTML / CSS / JavaScript 构建，通过 GitHub Pages 自动部署。
My personal homepage, built with plain static HTML / CSS / JavaScript and auto-deployed via GitHub Pages.

> 当前为简洁的占位首页，后续会逐步丰富内容。
> Currently a minimal placeholder landing page; more content will be added over time.

## 技术栈 / Tech Stack

- **HTML5** — 页面结构 / page structure
- **CSS3** — 页面样式 / styling
- **JavaScript** — 交互逻辑 / interactivity
- **GitHub Pages** — 静态托管与部署 / static hosting & deployment

## 本地预览 / Local Preview

```bash
# 克隆仓库 / clone the repo
git clone https://github.com/vonos/-vonos-.github.io.git

# 用任意静态服务器打开（例如）/ serve with any static server (e.g.)
python -m http.server 8000
# 然后访问 / then open
# http://localhost:8000
```
